01처음 한 번만

한 번 해두면 그 폰에 저장됩니다. 다음부터는 03단계부터 하면 됩니다.

  1. GitHub 초대 메일을 수락합니다.

    musical-otk/fated2026 하나만 초대됩니다. 계정이 없으면 먼저 만드세요.

  2. GitHub에서 토큰을 만듭니다. PC·폰 브라우저 모두 됩니다.

    Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token
    · Scopes: repo 하나만 체크
    · Expiration: 2027년 2월 정도로

  3. 만들어진 문자열(ghp_로 시작)을 바로 복사합니다.

    창을 닫으면 다시 볼 수 없습니다. 잃어버리면 새로 만들면 됩니다.

  4. 관리 도구를 열어 GitHub 인증 칸에 붙여넣고 저장.

    자주 쓰니 홈 화면에 추가해두면 편합니다.

03캐스팅표를 JSON으로 바꾸기

ChatGPT·Claude 등 이미지를 읽을 수 있는 AI 앱이면 무엇이든 됩니다.

  1. X에서 캐스팅 스케줄 이미지를 폰에 저장합니다.

  2. AI 앱에 그 이미지를 올리고, 아래 프롬프트를 통째로 복사해서 같이 보냅니다.

  3. 답이 오면 전체를 복사합니다. 앞의 확인용 숫자가 섞여 있어도 괜찮습니다 — 관리 도구가 JSON만 골라냅니다.

캐스팅 스케줄용 프롬프트 
이 이미지는 뮤지컬 〈FATED〉의 캐스팅 스케줄표야.
표를 읽어서 아래 두 가지를 순서대로 출력해줘.

1) 확인용 숫자 — 대괄호는 절대 쓰지 마
   전체 회차 수
   아킬레우스: 박규원 N / 신주협 N / 박준형 N (합계 N)
   파트로클로스: 반정모 N / 조은성 N / 김재한 N (합계 N)
   헥토르: 이동수 N / 조민호 N / 신수빈 N (합계 N)
   세 합계는 모두 전체 회차 수와 같아야 해. 다르면 어디가 불확실한지 적어줘.

2) JSON 배열 — 이것 말고 다른 설명은 붙이지 마
[{"date":"2026-11-03","time":"20:00","achilles":"박규원","patroclus":"반정모","hector":"이동수"}]

규칙
- 키는 achilles, patroclus, hector 세 개만 쓴다. 다른 이름으로 바꾸지 않는다.
- date는 YYYY-MM-DD. 11~12월은 2026년, 1월은 2027년.
- time은 24시간 HH:MM. 표의 8시=20:00, 3시=15:00, 7시=19:00,
  2시=14:00, 6시=18:00, 4시=16:00.
- 하루에 2회 공연이면 같은 date로 항목을 두 개 만든다.
- 배우 이름은 아래 9명 중에서만 고른다. 비슷한 이름으로 추측하지 않는다.
  achilles: 박규원, 신주협, 박준형
  patroclus: 반정모, 조은성, 김재한
  hector: 이동수, 조민호, 신수빈
- 표에 없는 회차를 지어내지 않는다.

04올리기

  1. 관리 도구에서 대상 저장소 → fated2026 선택.

    고르면 현재 몇 회차가 들어있는지 표시됩니다.

  2. 📅 schedule.json 칸에서 📋 클립보드에서 붙여넣기를 누릅니다.

  3. 기존 일정과 병합 체크는 켠 채로 둡니다.

    끄면 기존 25회차가 통째로 날아가고 새로 올린 것만 남습니다. 같은 날짜·시각은 새 값으로 덮어쓰므로 캐스팅 변경도 병합을 켜두면 됩니다.

  4. 미리보기 표가 뜹니다. 여기서 멈추고 05단계를 확인하세요.

  5. 확인이 끝나면 업로드. 1~2분 뒤 앱에 반영됩니다.

05올리기 전 확인

가장 중요한 단계입니다. 틀린 캐스팅은 에러가 안 나고 그냥 조용히 올라갑니다.

AI가 적어준 합계부터 보세요

배역마다 세 배우의 회차를 더하면 전체 회차 수와 정확히 같아야 합니다. 한 칸이라도 밀려 읽혔으면 이 합이 깨집니다. 지금 들어있는 25회차는 이렇습니다.

아킬레우스 9+8+8 = 25 파트로클로스 9+9+7 = 25 헥토르 9+8+8 = 25

합계가 맞으면 미리보기에서 이 네 가지를 눈으로 봅니다.

  • 배우 이름이 아래 9명 안에 있는지 — 오타 한 글자면 앱에서 다른 사람이 됩니다
  • 날짜가 공연 기간 안인지 — 2026.11.03 ~ 2027.01.24
  • 월요일이 섞이지 않았는지 — 월요일은 공연이 없습니다
  • 시각이 24시간 형식인지 — 20:00이지 8:00이 아닙니다
achilles 박규원 · 신주협 · 박준형아킬레우스
patroclus 반정모 · 조은성 · 김재한파트로클로스
hector 이동수 · 조민호 · 신수빈헥토르
자주 나는 실수

공연 시각은 표를 그대로 믿으세요. 공식 안내에는 "화수목금 8시"라고만 적혀 있지만, 실제로 11월 18일(수)은 16시·20시 2회 공연입니다. 안내문이 아니라 캐스팅표가 정답입니다.

06특전 올리기

특전·이벤트 안내가 뜨면 🎁 events.json 칸에 같은 방식으로 올립니다. 지금은 비어 있습니다.

특전·이벤트용 프롬프트 
이 이미지는 뮤지컬 〈FATED〉의 특전/이벤트 안내야.
공지 주소: (여기에 트윗 주소를 붙여넣기. 없으면 이 줄을 지워)
JSON 배열만 출력해줘. 다른 설명은 붙이지 마.

[{"name":"이벤트명","startDate":"2026-12-01","endDate":"2026-12-14","color":"#B08D57","description":"무엇을 어떻게 받는지 한 줄","url":"공지 주소"}]

규칙
- 날짜는 YYYY-MM-DD. 11~12월은 2026년, 1월은 2027년.
- 기간이 하루뿐이면 startDate와 endDate를 같게 쓴다.
- color는 #B08D57, #123A6B, #6B8E4E, #9B2C2C 중에서 고른다.
- description은 한 줄로 짧게. 이미지에 없는 내용은 지어내지 않는다.
- url에는 위에 적어준 공지 주소를 모든 항목에 똑같이 넣는다.
  주소를 안 적어줬으면 url 항목 자체를 빼라. 주소를 지어내지 마.
공지 주소는 선택

넣으면 앱 달력의 그 이벤트 옆에 "안내 ↗" 링크가 생겨 원문으로 갑니다. 안 넣어도 이벤트는 정상 표시되고 링크만 안 보입니다.

넣으려면 프롬프트의 "공지 주소" 줄에 트윗 주소를 붙여넣어야 합니다. 올린 뒤에는 관리 도구에서 고칠 수 없습니다 — 미리보기는 보기만 되고 수정은 안 됩니다.

07직접 적을 때의 형식

AI 없이 손으로 올릴 때 쓰는 모양입니다. 한 회차가 한 줄이고, 하루 2회 공연이면 같은 날짜로 두 줄을 씁니다.

[
  { "date": "2026-11-23", "time": "20:00",
    "achilles": "박규원", "patroclus": "반정모", "hector": "이동수" },
  { "date": "2026-11-24", "time": "16:00",
    "achilles": "신주협", "patroclus": "김재한", "hector": "신수빈" }
]

왼쪽 이름(achilles · patroclus · hector)은 철자 그대로 써야 합니다. 바꾸면 앱이 캐스팅을 못 읽습니다.

08건드리지 않는 것

그대로 두세요

도장은 관람 1회차부터 1개씩입니다. 공식 안내에는 "2회차부터 발급"이라고 적혀 있지만, 앱은 의도적으로 다르게 만들어져 있습니다. 문의가 와도 버그가 아닙니다.

좌석도는 공식 좌석배치도 기준으로 211석(판매 197석)입니다. 극장 공표 좌석수와 달라도 그대로 둡니다.

schedule.json과 events.json 외의 파일은 이 도구로 건드리지 마세요.

09막혔을 때

  • 저장소 목록이 비어 있음 — 토큰이 저장 안 됐거나 만료됐습니다. 다시 붙여넣어 보고, 안 되면 01단계로 새로 만드세요.
  • 업로드에서 권한 오류 — fated2026이 아닌 저장소를 고른 겁니다. 다시 확인하세요.
  • "클립보드에서 JSON 배열을 찾지 못했습니다" — AI 답에 JSON이 안 들어갔거나 확인용 숫자에 대괄호가 섞인 경우입니다. 프롬프트를 다시 보내거나 07단계처럼 직접 적으세요.
  • 업로드는 됐는데 앱이 그대로 — 1~2분 기다린 뒤 새로고침. 그래도 안 바뀌면 브라우저 캐시만 지웁니다. 사이트 데이터는 지우지 마세요 — 관람 기록이 거기 있습니다.
  • 회차 합이 안 맞음 — 올리지 마세요. 이미지를 확대해 다시 읽히거나, 07단계처럼 직접 적으세요.
  • 잘못 올렸음 — 고칠 수 있습니다. 올바른 값으로 한 번 더 올리면 같은 날짜·시각의 회차를 덮어씁니다(병합 켠 상태). 지워야 하는 회차가 생겼다면 07단계처럼 전체를 직접 적고 병합을 끄고 올리세요 — 이때는 올린 것만 남습니다.
