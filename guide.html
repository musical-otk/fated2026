🏠 홈

  • 예정 일정 목록 (설정에서 표시 배역 선택)
  • MANIA CARD 현황
  • 최근 관람 이력 + 마일스톤 달성 표시
📅 캘린더
  • 배역 탭 → 배우 선택 → 해당 회차 필터
  • ✅ = 기록한 회차
  • 날짜 클릭 → 회차 목록 + 기록 추가/상세
🎫 MANIA CARD
  • 7칸 도장판 — 관람 1회당 도장 1개
  • 3회 달성 → 🎴 포토카드 9종
  • 7회 달성 → 📸 지정 폴라로이드 1장 + 💿 실황 OST
  • 이력 패널에서 달성 날짜·혜택 변경
  • 이 작품은 실물 할인권·쿠폰이 없어 쿠폰 현황은 비어 있습니다
😌 통계
  • 히트맵 — 좌석 방문 횟수 (단층 A~L열)
  • 배우별 — 역할별 관람 횟수
  • 조합별 — 3×3×3 전체 조합, 행 클릭 시 날짜 목록
  • 지출 — 총 지출 / 평균 티켓가
📝 팁
스케줄 연동 — 날짜 클릭 → 회차 옆 "+ 기록"으로 캐스팅 자동 입력
MANIA CARD — 기록 저장 시 도장판 선택하면 자동 도장. 7칸 초과 시 새 카드 자동 생성 (기존 카드에 합산 불가)
현장 규칙 — 발급·날인은 MD부스에서 공연 시작 1시간 전 ~ 10분 전, 종료 후 10분까지. 당일 카드 미지참 시 적립 불가
양도 — 표는 있었지만 못 본 회차는 "양도"로 표시. 도장·통계·지출에서 빠집니다
사진 첨부 — 원본 화질 저장. 탭: 전체화면 / 두 번 탭: 가로 꽉채움
데이터 백업 — 설정 → JSON 내보내기/가져오기. 사진 포함 옵션 있음
